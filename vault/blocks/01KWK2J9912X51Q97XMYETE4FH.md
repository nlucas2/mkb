## Developer's note
mkb has its fair share of bells and whistles, but there is no single "right" way to use it. You don't **have** to use every feature. It's a simple, versatile tool. Use the parts that fit your workflow and how *you* want to use it.  

 - Want to use tags? Use tags. 
 - Want to use paths? Use paths!
 - Want index blocks that link to sub-blocks, viewed through the hierarchy? Do that!

Most of the features are just there to help a workflow that was brought up to me.  
The only reason *this* repo's own docs exercise every feature is **dogfooding** — I used all the features in this repo's vault so I can make sure the features don't break in the dev loop. In my own workflow (what inspired this project), I don't use paths at all. Not every tag system needs some hierarchical structure either!

The base form with Search and Transclusions should be more than enough for standard use cases, and if you want to decorate your notes with tags or paths, knock yourself out!
